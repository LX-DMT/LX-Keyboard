# 接收器使用说明


## 作用

接收器插入电脑后呈现 USB HID 键盘、鼠标和媒体输入接口，以及配置用 CDC 接口。它接收已绑定键盘通过 Wi-Fi 或 ESP-NOW 发来的输入，并转为 USB HID；普通输入不要求上位机常驻。

## 绑定和连接

首次使用需要通过配套产品 USB 配置工具，将两端身份和同一组配对密钥保存到各自设备。**插入接收器不等于已与任意键盘配对。** 本发布副本已删除固定开发板地址回退，没有出厂通用密钥。

- Wi-Fi：两端配置同一可互通的 2.4 GHz 网络，键盘选“接收器 Wi-Fi”。路由器客户端隔离会阻止发现/连接。
- ESP-NOW：两端已绑定且信道一致，键盘选“接收器 ESP-NOW”。没有路由器也可传输输入；切换网络或路由器信道后需重新确认两端信道。
- 同时插着产品 USB 和下载器时，以键盘选中的模式决定输入链路。

在[上位机](https://github.com/LX-DMT/LX-Keyboard/blob/main/pc_app/README.md)的“配网”页同时选择键盘和接收器，按向导验证并保存。协议的事务流程见[协议说明](PROTOCOLS.md)。

## GPIO13 状态灯

低电平点亮，硬件 PWM 控制亮度。

| 灯效 | 含义 |
| --- | --- |
| 应用启动短亮约 300 ms | 程序开始运行 |
| 每 2 秒短亮约 100 ms | USB 已就绪，等待键盘 |
| 约 3 秒一轮柔和呼吸 | 近期收到有效无线数据或心跳 |
| 约 250 ms 亮 / 250 ms 灭 | USB 未就绪或已报告初始化错误 |
| 完全熄灭 | 可能无供电；也需排除硬件和固件未启动 |

连接判断有约 2 秒保持时间，避免瞬时丢包让灯效频繁变化；不会每按一次键就闪灯。呼吸并不保证电脑应用已经收到每个事件，仍以实际输入为准。

## 下载接口

运行状态下的产品 CDC 串口不是 ROM 下载口，不能仅因设备管理器看到串口就直接烧录。可用 UART 下载接口；若需要原生 USB 下载，必须先以硬件 BOOT/EN 或可用外部控制线进入下载模式。无 BOOT 按键的板需接入下载控制线，进入 ROM 下载模式后选择对应端口，见[编译烧录](BUILD_FLASH.md)。端口号会变化，文档不固定 COM 号。
