# 故障排查

[返回首页](../README.md)

## 下载与构建

| 现象 | 检查 |
| --- | --- |
| SDK 版本拒绝 / Python 依赖缺失 | 打开 5.5.6 环境终端，核对 `idf.py --version` 和 `IDF_PATH`，用官方安装器补齐该版本工具 |
| 依赖找不到 / 引用旧路径 | 完整解压源码与 `third_party`，运行依赖校验；不要带旧 build、sdkconfig 和依赖锁 |
| 下载复位后键盘无响应 | 先退出串口程序，按平时方法重新开机并保持下载线，再重试；先看报告确认是否开始写入 |
| 接收器有 COM 口但连不上下载 | 区分产品 CDC 和 ROM 下载；检查 BOOT/EN 控制连接，进入下载后重新确认端口 |
| 旋钮烧录中断 | 检查稳定供电及键盘休眠；必要时使用 `--power-port`；检查 UART 是否被键盘/下载器同时驱动 |
| Wrong board / partition differs / insufficient Flash | 停止，核对目标硬件、分区和容量；不要跳过检查或直接擦除 |

## 输入和无线

- **USB 模式无输入**：检查产品 USB 数据线、模式和系统设备枚举。下载线连接正常不等于 HID 已连接。
- **蓝牙不连接**：先确认键盘在蓝牙模式、主机蓝牙开启；重新切换模式或在系统内重新连接。只有确认配对状态损坏后才删除旧配对并重新配对。
- **接收器一直慢闪**：检查绑定是否完成、键盘是否选接收器模式、两端信道与 Wi-Fi 网络。新设备不会自动连到开发板。
- **多个设备都在但选错链路**：以键盘当前输入模式为准。电脑负载同步的通道选择是外部软件功能，不能将它等同于键盘输入模式。
- **打字和鼠标同时变卡**：先把键盘和接收器临时靠近、避开遮挡及 USB3 干扰源，对比无线环境；检查丢包/发送失败，不能只看灯效。
- **休眠后鼠标不动**：先确认实体按键是否已唤醒键盘，检查 H1 供电、鼠标重新枚举和当前无线连接。

## 语音、灯光和旋钮

- **小智无法唤醒**：检查 Audio 开关、麦克风、Wi-Fi 和绑定状态；下载日志区分本地唤醒模型、服务器连接和播放任务。
- **回复噪声或断续**：分清网络等待、播放断流和真实削波；保留一轮完整会话日志，并记录是否移动 H1 鼠标、无线信号和模式。
- **语音输入乱码**：先确认原始识别结果，再检查 HID 输出和输入法；使用微软拼音“中”，等待出字结束，避免失焦。
- **律动安静时不亮**：它跟随麦克风声音，先说话或拍手；同时检查低电保护、亮度和休眠。
- **旋钮未校准无法确认**：按首次校准流程处理；不要用别的设备 NVS 覆盖本机。
- **切模式时灯短暂停顿**：保存/切换伴随重启，是当前已知行为。

## 日志与问题反馈

打开对应 IDF 工程的下载串口监视器，使用 115200 波特率。键盘可查询 `info`、`input`、`network`、`battery`、`controls`；接收器可查询 `info`、`input`、`network`、`led`。查询命令不等于全功能测试。

记录硬件版本、Flash/PSRAM、固件版本、输入模式、出现频率、操作步骤和相关错误。发布日志前去掉 SSID、IP/MAC、设备身份、账号/令牌等私人资料；不要上传 NVS、整片备份或录音。使用仓库的 Bug Issue 模板整理信息。
