# 使用限制

[返回首页](../README.md)

| 项目 | 使用限制 |
| --- | --- |
| 上位机 | 提供 Windows x64 版本；配网、小智、按键和灯光配置需要键盘产品 USB |
| 语音输入 | 依赖输入法、输入框焦点和应用处理速度，可能出现多字、乱码或漏字；建议使用 Windows 微软拼音中文状态 |
| 无线与语音 | 弱信号、干扰、丢包和服务响应会影响输入延迟及声音连续性 |
| 模式切换 | 保存并切换模式时输入和灯光可能短暂停顿或重启 |
| 下载复位 | 无应答时重新开启设备，再进入下载模式重试 |
| 内存 | 音频任务栈与 DMA 需要片内 RAM；扩展 PSRAM 不能替代这些内存需求 |
| 硬件 | 需满足最低容量、存储接口、电压和 GPIO 要求；未覆盖所有模组组合 |
| 首次烧录 | 工厂镜像流程会清除配对、账号凭据、网络、灯光和校准设置，需重新配置 |
| 兼容性 | 其他操作系统、输入法、鼠标私有协议和全部附加按键需自行验证 |

素材和第三方依赖的授权范围见[许可说明](LICENSING.md)。
