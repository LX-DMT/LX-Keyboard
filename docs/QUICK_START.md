# 快速开始

[返回首页](../README.md)

## 1. 确认硬件和固件

三块设备均为 ESP32-S3，但引脚、分区和用途不同，固件不可互刷。先核对[硬件要求](HARDWARE.md)，然后按[编译烧录说明](BUILD_FLASH.md)构建对应设备。

现有设备使用备份升级流程保留配对、网络和旋钮校准。空白设备启动后需要校准和配置，不会自动获得开发者的账号或配对。

## 2. 先验证 USB 基础输入

1. 给键盘供电并开机，通过旋钮连接菜单选择 USB。
2. 用数据线将键盘的**产品 USB** 接口接到电脑。下载器的串口线不能替代产品 USB。
3. 打开空白文本框，测试实体字母、方向键和 Del。
4. 如连接 H1 鼠标，再测试移动、左右键和滚轮。

若旋钮首次启动进入校准，请按[旋钮使用说明](KNOB.md)完成；尚未完成校准时可能无法用按压确认菜单。开发者也可通过键盘下载串口发送 `mode usb`，该命令保存模式并重启。

## 3. 选择连接方式

| 模式 | 操作 | 是否需要接收器 |
| --- | --- | --- |
| USB | 旋钮选 USB，连接产品 USB 数据线 | 否 |
| 蓝牙 | 旋钮选蓝牙，在系统中配对 `LX Keyboard Dev` | 否 |
| 接收器 Wi-Fi | 键盘和接收器完成绑定、加入同一可互通的 2.4 GHz 网络；接收器插电脑 | 是 |
| 接收器 ESP-NOW | 键盘和接收器已绑定、信道一致；接收器插电脑 | 是 |

旋钮选择的模式决定键盘输入走哪条链路，不因同时插入接收器就自动改变。接收器灯变为呼吸表示近期收到有效数据或心跳；还需实际打字确认电脑端正常。

## 4. 首次配网与语音

配套配置工具通过产品 USB 将 Wi-Fi 和绑定资料写入设备。操作配置工具时，键盘需要切到 USB 模式并连接电脑；同时配置接收器时也应连接接收器产品 USB。配置成功后再切到无线模式使用。

打开[上位机](../pc_app/README.md)的“配网”页，按向导完成网络配置和接收器绑定，再到“小智”页开始官方激活。

小智需要 2.4 GHz Wi-Fi、可访问服务的网络及官方绑定。官方绑定时获取六位验证码，在[小智官方控制台](https://xiaozhi.me/)按网站当前流程添加设备。按键灯辅助显示只在主动配置期间启用。详见[键盘说明](KEYBOARD.md)。

## 5. 建议验收顺序

先 USB → 蓝牙 → 接收器 Wi-Fi → 接收器 ESP-NOW；每个模式测试实体打字与 H1 鼠标。再测试休眠唤醒、灯光、小智唤醒与回复、语音输入。语音输入应在可清空的文本框测试，先确认输入法为微软拼音中文状态。

发生问题时记录设备、模式、固件和复现步骤，参照[故障排查](TROUBLESHOOTING.md)。
