## 自有部分

自有部分采用 LX 非商业源码许可 1.0。许可适用于权利人有权授权的原创部分，允许非商业使用、修改和再分发，商业使用须另行取得有关权利人授权。

这不是 OSI 定义的开源许可。README、仓库介绍及将来的 Release 不应将其标为 MIT、Apache、GPL 或“可自由商用”。

## 第三方代码与二进制

`third_party/` 保留原组件的版本、许可证、源码、模型及预编译库，内容由锁文件记录。库的“源码随仓库提供”不意味着所有算法和模型都具有可重建源码。

- MIT、Apache 等组件仍遵循原许可；项目的非商业条款不能收回第三方原本授予的权限。
- ESP-SR 使用 ESPRESSIF MIT License，许可中包含 Espressif 产品限制；ESP Audio Codec 使用 Espressif Modified MIT，限定与 Espressif 产品一起使用。请直接阅读组件原文。
- LVGL 的许可文件名为 `LICENCE.txt`，不要因拼写不同遗漏。
- `espressif__dl_fft` 清单声明 MIT，但当前随附快照未发现独立 LICENSE 文件；正式发布前需要依据确切版本上游补齐/确认许可文本，不能把其他库的许可证直接当作该组件许可证。
- 源码中其他保留的版权、来源或许可说明同样有效。许可清单不能取代逐项审核。

## 素材清单与待确认项

| 内容 | 当前可确认的来源 | 发布前需要确认 |
| --- | --- | --- |
| 旋钮 UI 图标、背景及动画 C 数组 | 转换为 LVGL 8 资源的旋钮素材 | 原始设计、作者及再分发授权；包括宇航员图片、表盘和动画帧 |
| 本地验证码 0–9 / 提示音 | Windows Microsoft Huihui Desktop 离线语音生成 | 对所生成语音的再分发条件；没有以本许可宣称获得微软授权 |
| 开关机提示 PCM | 由 WAV 转换；来源与摘要见 manifest | 原音频权利来源及允许再分发的依据 |
| LVGL 字体及示例素材 | 随第三方 LVGL 快照提供 | 保留字体和素材原有声明，不归为项目原创 |
| Espressif 模型、预编译库 | 对应固定版本组件 | 遵循原许可和芯片使用范围 |

上述资源的构建可用性不代表其已取得对外再分发授权。确认不了来源的素材应在正式发布前替换成自制或授权明确的资源，并重新构建验证。
