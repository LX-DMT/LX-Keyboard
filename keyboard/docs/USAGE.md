# 键盘使用说明


## 四种连接模式

键盘通过旋钮连接菜单切换 USB、蓝牙、接收器 Wi-Fi、接收器 ESP-NOW。切换会保存模式并重启相关固件流程，期间输入和灯光可能短暂停顿。不要在正在自动输入文字或语音对话时频繁切换。

USB 模式需要产品 USB 数据线；蓝牙模式配对名称为 `LX Keyboard Dev`。接收器两种模式都要先完成键盘与接收器绑定，接收器以 USB HID 向电脑输入。Wi-Fi 模式还要求同一可互通的 2.4 GHz 局域网。ESP-NOW 不要求路由器承载输入，但两端必须在同一无线信道；同时使用小智 Wi-Fi 时尤其要注意信道变化。

## H1 鼠标转发

将兼容的 USB HID 鼠标接到 H1，键盘将鼠标输入转发到当前选中的链路。测试时分别检查移动、左右键、滚轮；复杂游戏鼠标的私有协议或全部附加键不保证兼容。

休眠唤醒后应恢复鼠标通信。若异常，先确认实体键盘输入是否正常，再按[排查步骤](https://github.com/LX-DMT/LX-Keyboard/blob/main/docs/TROUBLESHOOTING.md)区分 USB Host、无线链路和电脑问题。

## 小智语音

1. 完成网络配置和官方绑定，确保音频开关开启。
2. 说“你好小智”，等唤醒回应结束后再提问。
3. 对话依赖键盘 Wi-Fi 接入互联网，与实体输入选用 USB、蓝牙还是接收器是两回事。

首次官方激活需通过配套配置工具主动开始。收到六位验证码时，键盘播报数字并辅助点亮对应数字键，按网站当前流程填写。正常绑定完成且退出配置后恢复原灯效；普通使用不应一直显示配置灯光。已经绑定的设备更换账号前需在官方控制台解除原绑定。

本仓库不提供账号、令牌、付费服务或服务可用性承诺。Wi-Fi 弱信号、丢包、服务异常可能导致回复等待、断续；目前播放具有预缓冲，但不能消除所有网络影响。

## 语音输入

在目标输入框获得焦点后，按住语音键说话，说完松开，等待文字输入完成后再操作。语音识别结果由键盘编码为 HID 按键序列，**不经上位机代打**。

请使用 Windows 微软拼音中文状态，并保持目标输入框获得焦点。输入法状态、候选窗口及应用处理速度可能造成多字、乱码或漏字；识别错误与输入输出异常需分别排查。

## 自定义按键

仅方向键区旁原 Del 和原旋钮电量预览两个实体键可配置，扫描编号为 bit82 / bit84。默认分别为 Del 和电量预览。保存到键盘后跨模式生效；修改映射请连接产品 USB，并使用上位机的“按键”页。

支持动作的代码定义见 [input_core.h](../components/input_core/include/input_core.h)；其他键不在本版自定义范围。

## 灯光、电量与休眠

日常可通过旋钮选择常亮、呼吸、律动及颜色。声音律动读取麦克风音量包络，安静时灯光可能较暗或熄灭。可选效果以上位机和旋钮界面为准。

低电量自动关闭装饰灯默认开启，可由配套 USB 工具修改并保存。该设置不改变四颗电量指示灯、定时休眠和关机规则。休眠关闭装饰灯并切断旋钮供电，唤醒恢复。

GPIO6 的 SD 使能为低有效：USB 模式拉低，其他三种模式拉高。这只说明板级使能控制，不代表任意读卡芯片、文件系统或 SD 容量已经验收。
